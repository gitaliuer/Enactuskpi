# Проверки и статус передачи · 17 ноября 2026

## Выполнено в sandbox

- Репозиторий изначально содержал только README, изменений пользователя не было; работа на предоставленной ветке.
- Версии библиотек взяты из npm registry, lockfile сохранён; npm audit после установки: 0 уязвимостей на момент проверки.
- Чистые SQL-миграции 001/002 успешно применены на PGlite (реальный PostgreSQL WASM), включая constraints, indexes и advisory lock. Повторный запуск миграций безопасен.
- 27 Vitest-тестов: QR интервал/подпись/версия/истечение, 0/199.9/200/200.1/250 м, неверные/неточные/устаревшие координаты, CSV injection, Argon2, активация и блокировка, отзыв sessions/grants, единственный OWNER, IDOR, параллельные входы, неизменяемый уход, задачи с приёмкой и историей, анонимный отзыв и отчёты.
- 3 Playwright E2E в Chromium с настоящими HTTP/API и локальной БД: вход, создание отдела/задачи, сохранение после reload, CSRF rejection, отсутствие эскалации у участника, закрытый экспорт и чужие задачи, QR deep link → вход → явная геоотметка прихода/ухода → закрытие → анонимный отзыв. Геолокация здесь **mock**.
- Скриншоты desktop 1280 и mobile 390, тест отсутствия горизонтального overflow. CSS рассчитан начиная с 360 px; интерфейс не использует внешний шрифт/CDN.
- `lint`, `typecheck`, production `build` проверяются командами из README. Итог последнего запуска см. передачу в чате; повторить после любых новых изменений.

| Что                                                                    | Почему / что нужно                                                                                                       |

## Решения разработки, требующие подтверждения владельца

Уход без QR; accuracy<=100 м; freshness<=30 с; challenge 60 с; password>=12 символов; sessions 7 суток; приглашения 24 ч, OWNER 1 ч; допуск к отзыву по ожидаемому списку после CLOSED; русский UI; один последний активный отдел для снимка участника командного собрания. Фиксированные обязательные параметры: QR 180 с, радиус 200 м, никаких ручных отметок и постоянного GPS.
